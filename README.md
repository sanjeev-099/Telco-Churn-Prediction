# Telco Customer Churn

Analysis project for the IBM Telco Customer Churn dataset using exploratory data analysis, statistical testing, visualization, and churn prediction.

## Current repository contents
- `requirements.txt`: Python dependencies
- `results.json`: analysis and model evaluation results
- `src/make_notebook.py`: notebook-generation helper

## Upload status
This repository currently contains only the files listed above. The dataset, main analysis script, executed notebook, figures, interactive charts, and PDF/DOCX reports from the original ZIP have not yet been uploaded.

Dataset source: https://github.com/IBM/telco-customer-churn-on-icp4d
